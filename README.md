# Kenya Drug Index

Field reference for Kenyan health workers: KEML 2023, KNMF 2023 monographs, live PPB trade names, and Kenya protocol notes for malaria, HIV, TB and NCDs.

## Live app

https://oseko-byte.github.io/kenya-drug-index/

Search a generic or a Kenyan brand (Coartem, TLD, Panadol, Ventolin).

## Sources

- Ministry of Health Kenya Essential Medicines List 2023
- Kenya National Medicines Formulary 2023
- Public PPB product register (via MedStatus Kenya index)
- NASCOP / NTLD / national malaria and NCD practice notes

Confirm packs on [products.pharmacyboardkenya.org](https://products.pharmacyboardkenya.org/ppb_admin/pages/public_view_retention_products.php). Report ADRs via [PPB PvERS](https://pv.pharmacyboardkenya.org/). Not a substitute for KNMF or clinical judgement.
